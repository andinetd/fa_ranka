# Security Policy

## Supported Versions

We maintain the latest `main` branch only.

## Reporting a Vulnerability

If you find a security issue, do not open a public issue.

Please report it privately to the maintainers by:

- Describing the vulnerability clearly.
- Including affected files or components.
- Sharing reproduction steps if safe to do so.
- Avoiding any private account data, phone numbers, or SMS contents in the report.

## Sensitive Data

This project processes financial SMS content. Do not submit screenshots, logs, or sample messages containing personal or financial information unless they have been fully redacted.
